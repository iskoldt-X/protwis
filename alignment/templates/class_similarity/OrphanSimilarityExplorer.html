How to use the Similarity table

  • Each row lists the closest receptors by sequence similarity.
  • Click column headers to sort by identity or similarity.
  • Use “Include orphans” to toggle orphan receptors in the table.
  • Download the visible table with the button on the right.

How to use the Cluster embedding

  • Each point represents a receptor, clustered by sequence similarity.
  • Hover to see labels, click and drag to zoom or pan.
  • Use the “Color by” dropdown to group by Class or Ligand type.
  • Download the plot as PNG or SVG from the Download button.
